# G music 0.27

Android 音乐播放器：本地音乐、HTTPS 音频直链、B站公开视频音频、通知栏控制、音频可视化和静态主题。

## 本版更新

0.27 新增独立歌单和「猜你喜欢」：

- 首页左上角「歌单」创建歌单；点击打开，长按歌单改名或删除。歌单内可批量添加喜欢 / 播放列表中的歌曲，点击歌曲按歌单顺序播放，长按歌曲移出或加入其他歌单。同一首歌可在多个歌单中；移出或删除歌单保留喜欢和音频文件。长按主界面心形按钮可把当前已载入的单曲加入歌单。
- 「更多 → 猜你喜欢」分为歌库推荐和联网发现新歌。按常听 / 喜欢的歌手从现有歌库推荐，避开当前歌曲和最近一天已听满 30 秒的歌曲；没有歌手信息时可从喜欢中重新发现。推荐仅按元数据匹配，不进行音频风格识别。
- 从本版本开始记录实际播放的单调时钟时长，单次满 30 秒才作为常听依据，暂停、加载和拖动进度期间不计入；历史最多保留 300 首。清除记录会保留喜欢与歌单。更新前的收听无法补算。可以用已有喜欢作为初始偏好。
- 联网发现新歌沿用 B 站公开视频搜索，最多取三组歌手 / 歌名关键词，过滤过短、过长和合集视频，以及已知 / 不感兴趣的来源。可换一批，长按不感兴趣；只发送查询关键词，不上传完整历史。2026-10-21 本机实测公开搜索返回 HTTP 412，不能承诺目前能在应用内取到新歌；失败界面提供用户主动打开 B 站搜索和返回歌库推荐的入口。
- JSON 备份新增歌单和播放记录，兼容旧 `gmusic.library.v1` 备份，重复合并不累加播放次数。不感兴趣列表留在本机，当前不进入备份。
- 已通过歌单增删改、持久化与容量限制、收听资格/暂停/重复播放、歌库推荐及新歌过滤、备份兼容与重复恢复、服务播放及收藏/队列/视觉设置回归。真实页面触摸、文件选择和联网新歌仍需安装体验。

0.26 优化横竖屏交接、暂停时开销和视觉设置备份：

- 横竖屏按页面独立登记音频分析使用权。页面切换后保留分析缓存 1.5 秒，新页面及时接入时复用已预热的解码器；旧页面迟到的销毁不会关闭新页面的分析。暂停或离开页面超过宽限期后关闭分析，切歌、清空或手动重新分析立即关闭旧分析器。
- 播放状态、通知栏控制、喜欢及模式变化直接通知当前页面；只有播放时定时更新进度，暂停后停止进度刷新和定时进度存盘。横屏去掉重复轮询，图形按播放状态刷新；文字未变化时不重复设置。
- 数据备份新增圆圈大小、跳动幅度、频谱条高度，恢复确认中列出将替换的值。旧备份不含视觉设置时保留当前效果；无效参数整份拒绝恢复。继续合并收藏和列表，保持当前歌曲及播放进度，兼容原来的 `gmusic.library.v1` 格式。

0.25 新增「更多 → 视觉调节」，使用三个滑块实时调整上方当前歌曲的视觉效果：

- 圆圈大小：70%–115%；跳动幅度：0%–200%，控制圆圈起伏和中间波形；频谱条高度：50%–180%。100% 对应 0.24 的默认效果。
- 调节区保留播放 / 暂停、「恢复默认」和「完成」；返回键也可退出调节。小屏幕可滚动滑块区域，上方仍保留声音图形。
- 松手自动保存，键盘 / 无障碍调节短暂空闲后保存；离开页面时保存最后一次调整。重启与横竖屏共用这份设置；恢复默认同时重置三个值。
- 调节只更新绘图参数；沿用同一播放和音频分析过程。较大参数下限制图形边缘，避免裁切。

0.24 修复播放途中视觉停住的问题，视觉尺寸和幅度沿用 0.23：

- 原分析队列按 160 个采样包限制，在 96/192 kHz 音源中不足以覆盖提前解码的内容，会把当前播放位置的数据提前挤掉。改为按约 20 毫秒间隔保留分析窗口，缓存覆盖当前时间及后续约 6 秒，并保持内存上限。
- 在线音源提前读取下一数据块，缓存锁不包住网络请求；临时读取失败重试，异常中断或已知时长音源提前结束时重新建立分析。网络读取耗时不再误判为用户拖动进度。
- 可视化仍来自当前音频；暂停、静音和真正没有新采样时保持静止。

0.23 微调视觉比例：圆圈整体缩小约 7%，跳动位移再收小约 9%；下方频谱条在相同音频信号下加长约三分之一。横竖屏同步调整，保持平滑响应。

0.22 修复四项播放与导入问题，保留 0.21 的视觉尺寸、线条和平滑幅度：

- 加载期间点击暂停、拔出耳机或丢失音频焦点，音源准备完成后不会擅自播放。加载时主界面与通知栏显示可用的暂停按钮；连续暂停 / 继续使用同一次加载。暂时失去焦点后，手动暂停会取消自动恢复。
- 播放列表的同来源重复歌曲按实际点击的行播放、标记当前行，拖动后也能准确定位；收藏中的相同来源仍可复用队列歌曲。
- 批量导入本地音乐在后台逐首读取信息，显示进度并支持取消；无法读取的文件单独跳过。完成后按选择顺序一次加入队列；取消或关闭该页面会丢弃这一批尚未加入的结果。
- 保存当前歌曲在列表中的位置与播放进度；重启后恢复到该歌曲和时间，保持暂停，点击播放才继续。恢复时先定位进度再开始出声。重排、移出、清空列表同步保存，兼容旧版列表；播放中每 5 秒保存一次，暂停、拖进度及离开主界面也会保存。异常终止可能回退几秒。

## 安装与覆盖更新

安装包：`build/G-music-0.27.apk`。在 Termux 中复制到下载目录后打开安装：

```sh
cp ~/G-music-0.27.apk ~/storage/downloads/
```

包名仍为 `cn.pulse.player`，版本码 26，沿用原签名，可直接覆盖更新并保留收藏、播放列表和设置。最低 Android 8.0，目标 Android 15。若系统提示签名冲突，保留原应用并检查安装包来源。

## 现有功能

- 列表循环、单曲循环、随机播放，模式自动保存。单曲循环时手动切歌仍有效，随机播放多首时避免立即重复。
- 播放列表与收藏列表右划：移出队列／取消喜欢，以及下载；移出队列不删除文件或收藏。喜欢列表支持搜索、长按取消喜欢、检查疑似重复。
- 跨来源收藏去重提示：结合歌名、歌手、版本、时长；疑似重复由用户决定保留，不自动删除。
- B站搜索原地播放；支持 BV 视频链接、BV号、b23.tv 短链和分享文字。多分集保持独立 CID 和时长。
- 歌曲行右划后点击「下载」，交给系统下载管理器保存到 `Download/G music`。
- 通知栏与锁屏播放控制、音频焦点、耳机拔出暂停。音乐由前台服务继续播放，系统强行停止应用会停止音乐。
- 鼓点圆环、原始音频波形、频谱；声音分析不依赖扬声器音量。双击特效进入纯黑横屏专注页，再双击或返回退出；保持亮屏。
- 「更多 → 数据备份与恢复」导出和合并收藏、歌单、播放记录、播放列表、播放模式，并备份 / 恢复视觉设置，不包含音频文件、主题资源和系统文件访问授权。相同来源不重复导入；本地歌曲在卸载后可能需要重新授权。

## 构建

```sh
cd "$HOME/pulse-player"
sh build.sh
```

Java 源码在 `src/cn/pulse/player`，无第三方运行时库。需要 JDK、aapt2、zipalign、apksigner、D8/R8、API 35 的 `android.jar` 和 API 32 的 `android-res.jar`。本机构建工具准备好后，构建无需联网。

源码提交不包含 `tools/`、`build/`、签名私钥或签名密码。克隆后需在 `tools/` 放好 `android.jar`、`android-res.jar` 和 `r8.jar`，并确保其余构建工具位于 PATH。构建可覆盖原应用的安装包还需要恢复原 `tools/pulse.keystore`，将对应密码单独保存到 `tools/signing-password`，设置文件权限为 `600`；也可通过 `GMUSIC_SIGNING_PASSWORD_FILE` 指定本机密码文件路径。私有备份目录 `$HOME/.local/share/gmusic-signing/` 中同名的密钥与密码文件可作为回退来源。签名文件只在本机使用。

脚本会检查 `signing-certificate.sha256`，优先使用原 `tools/pulse.keystore`，缺少时读取本机私有签名备份。不会为现有应用悄悄生成新密钥。源码分享包包含代码、资源、测试、文档、公开签名指纹和示例，不包含密钥、SDK、音频缓存。
